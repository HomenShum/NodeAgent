Cross-collaborative agent · built on assistant-ui

The room asks. The agent answers — inline, with tool UIs.

NodeAgent is an assistant-ui chat. Ask the room a question and watch the agent gather context, find the right document for the right answer, update the model as a versioned delta, and write the memo — each step rendered as a tool UI inside the conversation.

Built on @assistant-ui/react · useLocalRuntime + makeAssistantToolUI. This page is the no-build mirror; src/app uses the real library.

Why this shape

NodeAgent is a career, compiled into four tool UIs

Each capability is the production form of a problem I already spent years solving — and assistant-ui renders each one inline as the agent works.
